# 🚗 Road Accidents Analysis in Italy 

## 📌 Overview

This project analyzes road accidents in Italy between **2001 and 2024** using official **ISTAT Open Data**.

The project includes a complete data pipeline developed in Python and an interactive dashboard created in Power BI to explore temporal, territorial and demographic trends.

---

## 🛠 Technologies

- Python
- Pandas
- Requests
- Jupyter Notebook
- Power BI
- Azure Maps
- ISTAT SDMX API

---

## 📊 Dashboard Features

- KPI cards
- Time trend analysis
- Interactive Azure Map
- Province filter
- Time filter
- Top municipalities by accidents
- Demographic indicators

---
## 📈 Data Source

Official ISTAT SDMX API:

https://esploradati.istat.it/
